\begin{abstract}
%
In this paper we explore the task of creating a composite image given a natural language prompt from a set of given primitives, such as combining “person” and “umbrella” to form “a person under an umbrella.” Each primitive is represented as a visual element, and a composition function arranges them spatially to form a complete scene. To guide this composition, we use CLIP to evaluate how well the rasterized image of the composed scene aligns with a natural language description of the target concept. The optimization objective is to maximize the cosine similarity between the image embedding and the text embedding produced by CLIP. 
%
\end{abstract}

% ------------------------------------------------------------------------------
\section{Introduction}

Our work focuses on the synthesis of complex composite image by stitching together a set of predefined primitives. Each target concept is associated with a collection of $k$ primitives, which are arranged to maximize the cosine similarity between the generated image embedding and the corresponding text embedding produced by CLIP. Initially, we implemented this task using the \texttt{pgpelib} library, where each concept was directly mapped to its corresponding primitives.

Early experiments revealed that our initial optimization methods were insufficient, leading us to explore alternative strategies. We discovered that the Covariance Matrix Adaptation (CMA) algorithm performed slightly better.

Despite the improvements provided by CMA, the performance of our method was hindered by a challenging loss function landscape. The loss, defined as the negative cosine similarity, exhibited many local maxima, which impeded the optimization process from converging to the global optimum. To address this, we modified the loss function by incorporating an additional component designed to smooth the landscape. This adjustment aimed to mitigate the effect of local maxima, thereby facilitating more robust convergence.

While this enhanced approach yielded to better results, it also introduced certain limitations that will be discussed in detail in the following sections.

\section{Related Work}
We based our work on the paper \textit{Modern Evolution Strategies for Creativity: Fitting Concrete Images and Abstract Concepts}~\cite{tian2022modernevolutionstrategiescreativity} (ES-CLIP). 

ES-CLIP presents a method that leverages evolutionary strategies to optimize image generation based on CLIP’s joint embedding space. 
An element in the \textit{population} is composed of a set of overlapping triangles eachone with its own vertex position and color. These features are optimized to maximize the cosine similarity between the CLIP embedding of the triangles rendered on the canvas and the CLIP embedding of a target prompt. 

Inspired by this work, we want to do something similar by composing visual scenes from a set of semantic primitives, instead of triangles.

In order to stitch together $k$ primitives to form a scene, we need to define a few components: the parameter to be optimized and the optimization strategy.

\subsection{Parameters \& Pipeline}
We represent the parameters as a matrix of shape $\left(k, 5\right)$ and each entry is bounded to be in the $[0, 1]$ range. Each row corresponds to one primitive and the five parameters describe its spatial attributes.   
\begin{itemize}
    \item \textbf{x, y}: the position of the top-right corner of the primitive with respect to the canvas size;
    \item \textbf{scale}: the relative size of the primitive (i.e. a percentage of the full primitive size);
    \item \textbf{rotation}: the angle of rotation $r \in [0,365]$ degrees normalized;
    \item \textbf{layer}: the rendering order (i.e., which primitives appear in front). We order the rasterization process, such that primitives with smaller layer parameter will be rasterized first, hence be in the back.
\end{itemize}
We created a \texttt{rasterize} function, which uses these parameters and the primitives to compose the scene and rasterizes it into an image. This image is then fed into CLIP’s image encoder to compute its embedding. The cosine similarity between this image embedding and the text embedding of the target prompt serves as the objective function.
An overview of this pipeline is shown in Figure~\ref{fig:architecture}.

\subsection{PGPE Optimization}
The first alghoritm we tried is PGPE (Probabilistic Gradient Population Evolution)~\cite{toklu2020clipup}, the one used in the ES-CLIP paper.
This algorithm is a gradient-free optimization method that uses a population of candidate solutions to explore the search space.
This method did not yield good results as in the implementation of the ES-CLIP paper. We belive that one of the problems here are the \textbf{sparse rewards}, we will discuss this further in the next section.

\subsection{CMA-ES Optimization}
To overcome the limitations of PGPE, we decided to use a more advanced Evolution Strategy implementation, the Covariance Matrix Adaptation Evolution Strategy (CMA-ES)~\cite{hansen1996adapting}.
Compared to PGPE, CMA-ES uses a more sophisticated sempling algorithm, which prioritize directions where improvement has been observed updating a multivariate Gaussian distribution.
Unfortunately even if it produces slightly better results compared to PGPE, this method do not brings a significant improvement. 

\subsection{Gradient-Based Approach}
In parallel, we also experimented with a gradient-based optimization method. We created a new rasterization function which is differentiable and has some limitations: rotating the primitives was pretty hard, so we decided to implment it only if a preliminary test would have been promising. This function allowed us to compute gradients of the cosine similarity loss with respect to the primitive parameters and apply gradient descent to improve the layout.
Unfortunately it do not yielded good results as well.



\section{Problems}
In this section we will discuss the problems we encountered during the optimization process and why the ES methods didn't work as in the original paper.

\subsection{The Sparse Rewards Problem}
We hipothesized that one of the reasons our approaches didn't work is the fact that in our problem the solutions have very \textbf{sparse rewards}. It means that seampled points in the surroundings of a certain point in the solution space yelds inconsistent rewards values and not a clear gradient direction.
If the best solution is far from the sampled points, the algorithm will not be able to reach it, since intermediate solutions do not provide an incremental improvement in the reward.
Therefore the loss landscape is very noisy, often inconsistent, has many local minimum and it is has a lot of "flat regions" (i.e., regions where the loss does not change much).
It means it is difficult for the algorithm to find a path to reach the optimal solution without running into a local minimum.

\subsection{The CLIP problem}
We decided to investigate the sparse rewards problem further and we wondered why our loss landscape was so noisy. We found out that the CLIP model is not very good at distinguishing between similar images.

\subsection{More on the loss landscape}
After the observation we did before we decided to explore the loss function's landscape. In \autoref{fig:landscape}plotted the contour plot of the loss landscape. We choose a simple example "A person under un umbrella", that has two primitives: \textit{person} and \textit{umbrella}. We embedded every combination of $(x, y, scale)$ parameters with values $0.3 , 0.38, 0.46, 0.54, 0.62, 0.7$ for both primitives, while keeping the rotation and layer fixed.
We confermed empirically that the loss function is very noisy, has many local optima and flat regions.
To give a further proof of the loss flatness zones, we computed the \textit{Coefficent of variation} of the values we computed in \autoref{fig:landscape}. The coefficient of variation is a measure of the relative variability of a distribution, a low value indicates that the values are close to the mean. The Coefficent of variation is $0.0583$, it means that the values are very close to the mean and that the loss function is very flat.

\section{Conclusions} 
Despite implementing several optimization strategies, including PGPE, CMA-ES, and gradient-based methods, our results fell short of expectations. Our investigation revealed significant challenges that impeded the optimization process: 
\begin{itemize}
    \item sparse rewards in the solution space making convergence difficult
    \item inconsistencies in CLIP's ability to discriminate between semantically meaningful and random arrangements
    \item a highly non-convex loss landscape with numerous local optima and flat regions.
\end{itemize}

These findings suggest that future work should focus on developing more robust optimization algorithms specifically designed to navigate sparse reward landscapes. Additionally, incorporating auxiliary reward signals or hierarchical optimization approaches might help guide the search process more effectively. Pre-training on simpler compositions before attempting more complex scenes could also provide a more informed initialization for the optimization process.
